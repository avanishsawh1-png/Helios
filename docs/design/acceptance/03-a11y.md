# 03 — Accessibility

## Targets (from dashboard-spec)

- WCAG 2.2 AA contrast on text/badges
- Keyboard: nav, buttons, focus-visible ring (`--focus-ring`)
- `aria-live="polite"` on ModeBanner; `aria-busy` on loading DataState
- `prefers-reduced-motion` disables animations (CSS present)
- Status not color-only (StatusBadge includes text)
